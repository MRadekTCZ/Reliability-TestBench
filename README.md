My PhD project.
Test bench to test algorithms for lifetime extension of SiC carbite MOSFETs.
Texas Intrument microcontroller controll 2 inverters, both with 6 switches (Back 2 Back configurations, one works as inverter, second models the load).
Hardware allows for switching frequency adjustment and gate resistance change (control variables)
Gate Driver enable degradation indicator measurement - Rdson and Uth - for lifetime assesment

The goal is to apply Active Thermal Control (ATC) Methods and see their impact (improvement) on transistor lifetime.
Hipothesis - ATC improves MOSFET lifetime
